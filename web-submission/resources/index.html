What is Artistic?

A multimodal ASD screening system built for clinicians and researchers

Early and reliable screening for autism spectrum disorder remains challenging in low-resource settings. Artistic combines three complementary signal streams into a single fused prediction, with full explainability built in, not added as an afterthought.

Beyond prediction, the platform provides transcript-level behavioral annotations, global and local feature attributions via SHAP, and counterfactual what-if analysis so clinicians understand why a prediction was made.
