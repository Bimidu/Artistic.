Milestone 01
Project Proposal
Submission Date10 September 2025
Marks Allocated5%
FormatWritten Document + Presentation

Description

The Project Proposal is the first formal deliverable, outlining the research problem, motivation, and preliminary approach for the Artistic system. It establishes the research context (early ASD screening from speech), the chosen methodology (multimodal feature extraction and fusion), and the planned evaluation strategy using ASDBank corpora.

The proposal introduces the three-component architecture and justifies the choice of explainability methods (SHAP and counterfactuals) as core design requirements rather than post-hoc additions.

Key Deliverables

  • Proposal document with problem statement, objectives, and literature survey
  • Preliminary system architecture diagram
  • Dataset selection rationale (TalkBank / ASDBank)
  • Project timeline and resource plan
  • Proposal presentation slides

Milestone 02
Progress Presentation 1
Presentation Date07 January 2026
Marks Allocated15%
FormatLive Presentation + Q&A

Description

Demonstrates the initial implementation of the Artistic pipeline. The pragmatic-conversational feature extraction module is operational, the CHAT parser handles ASDBank corpora correctly, and a baseline SVM model has been trained and evaluated on cross-validated data.

This milestone covers the input handling pipeline, CHAT format parsing, and first results from the pragmatic component, including preliminary SHAP feature importance visualizations.

Key Deliverables

  • Working CHAT parser and pragmatic feature extractor (207 features)
  • Baseline SVM model training and evaluation results
  • Initial SHAP global feature importance analysis
  • API endpoints for feature extraction and basic prediction
  • Progress Presentation 1 slide deck

Milestone 03
Progress Presentation 2
Presentation Date10 March 2026
Marks Allocated18%
FormatLive Presentation + Q&A

Description

Demonstrates the full three-component system: acoustic-prosodic (153 features via librosa), syntactic-semantic (27 features via spaCy), the multimodal fusion layer, and the counterfactual explanation system.

All three component models are trained and the weighted fusion (50%/25%/25%) achieves 87.2% accuracy. The neural autoencoder for counterfactual generation is implemented and evaluated with 1.00 validity.

Key Deliverables

  • Full three-component feature extraction pipeline
  • Multimodal fusion, 87.2% accuracy, 0.92 ROC-AUC
  • Counterfactual explanation system (neural autoencoder)
  • React/Next.js frontend with interactive SHAP visualizations
  • AssemblyAI transcription + speaker diarization integration

Milestone 04
Final Assessment
Submission Date05 May 2026
Marks Allocated18%
FormatFinal Report + Presentation + Demo

Description

The complete, production-ready Artistic system, research paper, and a live demonstration. The system is fully deployed as a FastAPI backend with a React/Next.js frontend, supporting audio upload, CHAT transcript input, and real-time prediction with SHAP and counterfactual explanations.

Key Deliverables

  • Final research paper (IEEE-style)
  • Complete system codebase with documentation
  • Model registry with stored artifacts and evaluation metrics
  • Final presentation slides and live system demo
  • Individual member reports

Viva (Combined in Final Assessment)

Individual oral examination where each group member is assessed on their depth of understanding of the research, their component, and the system as a whole. Examiners probe technical decisions, results interpretation, limitations, and future directions.

Viva Preparation Areas

  • Feature engineering decisions and rationale for each component
  • Model selection (SVM vs RF vs GB) and hyperparameter choices
  • Fusion strategy and weight justification (50%/25%/25%)
  • SHAP explanations and counterfactual validity
  • Limitations, ethical considerations, and future work
